API reference

The server exposes {{endpoints}} endpoints, grouped here by area. Long-running work (jobs, missions, discovery and learning runs) returns an id at once, and its /events endpoint streams every step as server-sent events.

{{table:routes}}

All endpoints are served by backend/inkubit/api/app.py. The built frontend is served from the same origin. /api/health reports the model provider (Meta live, mock, or mock fallback), and the recorder and the interface read it before naming a model.

Reproducing every result

Every result in this report comes from a script in the repository. The offline ones run anywhere; the live ones need a Meta key, or an IBM Quantum key for the hardware run, and their answers are cached so a re-run is quick.

Set up and test

py -3.13 -m venv .venv
.venv/Scripts/python -m pip install -r backend/requirements.txt
cd frontend && npm ci && npm run build && cd ..
cd backend && ../.venv/Scripts/python -m uvicorn inkubit.api.app:app --port 8000   # http://127.0.0.1:8000
cd backend && ../.venv/Scripts/python -m pytest -q                                  # {{backend_tests}} offline tests
.venv/Scripts/python -m pytest e2e                                                   # browser tests (after the build)

Put META_API_KEY and INKUBIT_MODEL_PROVIDER=meta in .env for the live models; without them everything runs on the labelled offline models.

Glossary

Bell pair
Two qubits in the state (|00⟩ + |11⟩)/√2: measured, they always agree, yet each alone is a fair coin.
BB84, BBM92
Quantum key distribution protocols: BB84 sends single photons in random bases; BBM92 measures halves of entangled pairs. An eavesdropper raises the error rate (QBER).
Bloch sphere
A picture of one qubit's state as an arrow; an arrow shorter than the radius means the qubit is entangled or noisy.
CHSH, Mermin values
Bell-test numbers: above 2, no classical (local hidden-variable) explanation can produce the correlations.
Concurrence, negativity
Measures of entanglement between two qubits; zero means the pair is not entangled.
Conformal prediction
A way to put an error bar on a model's prediction that holds a stated fraction of the time for data like the calibration set.
CSS code
A stabilizer code whose generators are all-X or all-Z, so bit and phase errors are corrected separately.
Density matrix
The full description of a possibly noisy quantum state; simulating it exactly is what Inkubit's verifier does.
Digital twin
A simulation of a specific device, built from its own calibration data.
Distance (d, dX, dZ)
The fewest single-qubit errors (of any kind, X only, or Z only) that defeat a code without being detected.
DRAG
Derivative Removal by Adiabatic Gate: a pulse shape that cancels leakage and phase errors in weakly anharmonic qubits.
GHZ, W and Dicke states
Families of multi-qubit entangled states; GHZ is all-or-nothing, W shares one excitation, Dicke shares several.
Heavy-hex
IBM's chip wiring, in which each qubit has at most three neighbours.
Hellinger fidelity, total variation distance (TVD)
Ways to compare two probability distributions; TVD is the share of probability in the wrong place.
Λ (Lambda)
The factor by which logical errors fall when a surface code grows by two in distance; above 1 means the bigger code helps.
Leakage
Population escaping from the qubit's two levels into a third level of a transmon.
McNemar test
A paired test that compares two methods on the same samples by counting only where they disagree.
Minimum-weight perfect matching (MWPM)
The standard surface-code decoder: it pairs detection events along the most likely error chains.
Page limit
The average entanglement of a random state between two halves; random circuits approach it.
Phenomenological noise
A decoder-testing noise model with errors on data qubits and on check outcomes each round, but not from individual gates.
Process fidelity
How close two operations are for every input: |Tr(U†V)|²/d².
QAOA
The quantum approximate optimisation algorithm: alternating cost and mixing layers with tuned angles.
Richardson extrapolation, ZNE
Running a circuit at amplified noise and extrapolating back to zero noise.
SGP4, TLE
The standard propagator for satellite orbits, and the two-line element sets it reads.
Stabilizer code
A quantum code defined by commuting Pauli generators whose measurements reveal errors.
Surface code
A stabilizer code on a 2D grid with only nearest-neighbour checks; the leading design for large machines.
T1, T2
A qubit's energy-relaxation and dephasing times.
Tomography
Rebuilding a state from measurements in many bases.
Transpile
Compile a circuit onto a chip's native gates and wiring, adding SWAPs where qubits are not neighbours.
VQE
The variational quantum eigensolver: a quantum circuit with tuned angles whose measured energy is minimised.
Werner state
A Bell pair mixed with white noise, described by one fidelity F; the standard model of a noisy link.
